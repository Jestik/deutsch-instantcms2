Deutsche Sprachunterstützung für InstantCMS 2
==================================================

**INSTALLATION AUF EINER BESTEHENDEN WEBSITE:**
- Löschen Sie den Ordner "install" aus dem Verzeichnis "package".
- Laden Sie die verbleibenden Dateien über das [Admin-Panel](https://docs.instantcms.ru/en/manual/addons)


**NEUINSTALLATION DER CMS:**
- Kopieren Sie den Inhalt des Ordners "package" in das Hauptarchiv von InstantCMS.
- Starten Sie die Installation und wählen Sie "Deutsch" als Sprache aus.
